# Handoffs

One Markdown file per handoff between agents: `YYYYMMDD-HHMM-<from>-to-<to>-<slug>.md`,
started from `TEMPLATE.md`. What a handoff is, when to write one and the rules
every agent follows are in [`handoff.md`](../../handoff.md) at the workspace root.

The backlog queue (`backlog/`) says *what* to do; a handoff here says *where
someone stopped*.
