## Problem

Slice 4 of the upstream roadmap ("Platform") is only partly landed. A survey of
the current tree found these items missing or partial (the rest are already
implemented: bundle cache, ICU plural/params, plugin circuit breaker, static
asset cache headers, server-side datagrid):

- `route:check` and `data:audit` CLI commands.
- `Idempotency-Key` middleware (deduplicate a retried write).
- `Money` type and its ORM cast.
- Transactional outbox; notification contract with provider failover and quotas.
- Bounded in-memory cache with prefix flush.
- Fallback routes ordered last.
- DB i18n tenant override; validator errors as a structured `code`/`message_key`.
- Tenant-scoped storage disk with public-path validation.

## Evidence

- `engine/cli/app.py`: `route_app` has only `list`; there is no `data_app`.
- `grep -i materialized|outbox|idempotency|MoneyCast` under `engine/` finds
  prose or nothing.
- `engine/support/doctor.py` already implements `check_routes`/`_check_action`;
  only the focused `route:check` CLI is missing.
- `engine/cache/manager.py:63-110` `ArrayStore` is an unbounded dict with a total
  `flush()` and no prefix flush.

## Done when

- [ ] `route:check` reports route defects and exits 1 on an error.
- [ ] Every remaining Slice 4 item above is implemented with tests.
- [ ] Full suite green on SQLite and PostgreSQL in the framework container;
  ruff, engine-boundary and language gates clean.
