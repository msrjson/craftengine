## What changed

Every remaining Slice 4 ("Platform") item from
`.agents/plans/softpax-upstream-roadmap.md` is implemented, tested and
documented. One commit each:

- `f6c99a0` - **Money.** `engine/support/money.py` (`Money`,
  `CurrencyMismatch`) holds an exact `Decimal` amount in one currency and
  refuses to mix them; `MoneyCast` round-trips it through a JSON column
  (`engine/orm/casts.py`, cast name `money[:CUR]`). Guide: `postgres.md#money`.
- `83b1ef7` - **Idempotency-Key.** `IdempotencyKey` middleware
  (`engine/http/middleware.py`), opt-in via `IDEMPOTENCY_ENABLED`, scoped to
  the tenant and the authenticated user; the first request claims the key with
  `Cache.add()`. Registered in `bootstrap/app.py`; flags in
  `config/framework.py`. Guide: `cache.md`.
- `f0b61a1` - **`data:audit`.** `run_data_audit()` in
  `engine/support/doctor.py` reports `TENANT_COLUMN_NULL` (error when tenancy
  is on) and `FOREIGN_KEY_ORPHANED`; `SchemaBuilder.table_listing()` and
  `foreign_keys()` were added for the catalog introspection. CLI `data audit`
  exits 1 on an error. Guide: `cli.md`.
- `276542e` - **Fallback routes.** `Route.fallback()` flags a catch-all and
  the kernel sorts the route table with fallbacks last, so a `/{path:path}`
  cannot shadow routes declared after it (`engine/http/router.py`,
  `engine/http/kernel.py`). Guide: `routing.md#fallback-routes`.
- `de2c75d` - **Validator `code` + `message_key`.** `MessageBag.add()` records
  the rule and its translation key; `MessageBag.errors()` returns the
  structured form, and an HTTP `ValidationException` payload adds
  `error_details` beside the unchanged `errors` map. Guide: `validation.md`.
- `eee7062` + `3538b04` - **DB i18n tenant override.** `translations` gains a
  nullable `tenant_id` (forward-only migration
  `2026_10_07_000004_add_tenant_id_to_translations.py`); the `(key, locale)`
  unique index becomes two partial indexes and the lookup prefers the bound
  tenant's row. The fix commit makes the lookup fall back when the column is
  absent, so a scaffolded project that has not migrated still renders its copy.
  Guide: `localization.md`.
- `5e358a0` - **Tenant-scoped storage + key validation.**
  `engine/storage/paths.py` (`normalize_key`, `TenantScopedStorage`); a disk
  with `tenant_scoped` keeps each tenant under `tenants/<id>/` and refuses a
  call with no tenant bound; the local and S3 drivers validate every key, for
  files and URLs. `tenant` disk added to `config/storage.py`. Guide:
  `storage.md`.
- `8c46305` - **Transactional outbox.** `engine/events/outbox.py` writes the
  message on the caller's connection inside their transaction and `dev.py
  outbox relay` publishes committed messages to `Outbox.on()` handlers,
  at-least-once with backoff and the message's tenant bound. Forward-only
  migration `2026_10_07_000005_create_outbox_table.py`. Guide:
  `queues_events.md#transactional-outbox`.
- `b2f6bdc` - **Notification failover and quotas.** `MailManager` walks a
  mailer's `fallback` chain and skips a mailer over its per-window (optionally
  per-tenant) `quota`. Guide: `mail.md`.

Each change has an entry in `data/CHANGELOG.md` `[Unreleased]` and a new test
module (`test_money.py`, `test_idempotency_key.py`, `test_data_audit.py`,
`test_fallback_routes.py`, `test_validation_error_codes.py`,
`test_translation_tenant_override.py`, `test_storage_paths.py`,
`test_outbox.py`, `test_mail_failover.py`).
